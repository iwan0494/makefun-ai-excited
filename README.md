# ai-excited-01

Seekor koi raksasa bercahaya sedang melompat diagonal di atas skyline kota neon pada senja. Pola sisik putih dan jingga menangkap pantulan warna kota; pita cahaya cyan serta magenta membingkai momen puncak dan memberi arah gerak. Ikan dan skyline dirancang sebagai siluet besar yang tetap terbaca pada ukuran kecil.

Jalankan `python3 draw.py` untuk membuat `entry.png` dari bentuk-bentuk gambar yang digambar dengan Pillow. `main.ts` menyalin gambar itu ke `/output/entry.png`.
